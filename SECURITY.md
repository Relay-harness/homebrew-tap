# Security

Report vulnerabilities privately using [Relay Cat private vulnerability reporting](https://github.com/Relay-harness/relay-cat/security/advisories/new). Do not open a public issue containing secrets, private account data, or exploit details. The latest cask is supported; previous preview versions may no longer receive fixes.

The cask pins the release ZIP SHA-256. It does not remove quarantine, disable Gatekeeper, or grant data permissions. Preview apps are ad-hoc signed, not notarized. Read the application [security policy](https://github.com/Relay-harness/relay-cat/blob/main/SECURITY.md) and [privacy policy](https://github.com/Relay-harness/relay-cat/blob/main/PRIVACY.md) before connecting accounts.
